Have you wanted to have your FPS, coordinates and more always visible?

Well look no further as you can now have this!!

# Features:
- FPS
- Coordinates
- Server IP
- Biome
- Ping
- Position Customization
- You can make everything™ gay now

There's not really anything else to say, except for that you can toggle everything in the config (modmenu required to access config screen)

> [!WARNING]
> The HUD will NOT work in a development environment on fabric, due to me using java reflection for 1.21.x compat and dev-env using different mappings
>
> If you know a fix for this, please propose it as a PR

##### Contributing
If you are doing development on this mod and you plan to PR at some point, please make sure to test your changes fully before submitting a PR. 

Test all the features and test at least some versions. E.g. test 1.21.8, 1.21.5 and 1.21 on both Fabric and neoforge `gradle :fabric:runClient` `gradle :neoforge:runClient`

Also before PR'ing run `gradle fmt`, this will run the google Java Format thingi and make the code look not ass.


Thank you
